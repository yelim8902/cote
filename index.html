이론 정리

자료구조 · 알고리즘 요약

각 주제에 대한 간단한 개념 정리입니다. 시각화와 함께 보면 이해에 도움이 됩니다.

배열과 리스트

정적 배열 / 동적 배열 — 연속된 메모리에 요소를 저장. 정적은 크기 고정, 동적은 확장 가능.
2차원 배열 — 행·열로 구성된 행렬 형태의 자료구조. 행 우선/열 우선 저장 방식.
단일 연결 리스트 — 각 노드가 다음 노드만 참조. 삽입·삭제가 O(1)이 가능하지만 탐색은 순차적.
이중 연결 리스트 — 이전·다음 노드를 모두 참조. 양방향 탐색과 삽입·삭제에 유리.
원형 연결 리스트 — 마지막 노드가 첫 노드를 가리켜 순환 구조. 원형 큐 등에 활용.

스택과 큐

스택 — LIFO(후입선출). Push, Pop, Peek 연산. 재귀, 괄호 검사, DFS 등에 사용.
큐 — FIFO(선입선출). Enqueue, Dequeue. BFS, 대기열, 버퍼에 사용.
큐 (배열 기반) — 선형 큐는 빈 자리 낭비, 원형 큐는 인덱스를 나머지 연산으로 재사용해 공간 효율적.

트리

이진 트리 — 각 노드가 최대 두 개의 자식. 전위·중위·후위·레벨 순회가 대표적.
이진 탐색 트리(BST) — 왼쪽 < 부모 < 오른쪽. 탐색·삽입·삭제 평균 O(log n), 편향 시 O(n).
AVL 트리 — 균형 이진 탐색 트리. 높이 차가 1 이하로 유지되어 탐색이 O(log n) 보장.
Red-Black 트리 — 색 규칙으로 균형을 유지하는 BST. 실무에서 널리 쓰이는 균형 트리.
힙 — 완전 이진 트리 기반. 최대 힙/최소 힙으로 우선순위 큐, 힙 정렬에 사용.

정렬 · 탐색

버블 정렬 — 인접 원소 비교·교환. O(n²), 단순하지만 비효율적.
선택 정렬 — 구간에서 최솟값을 골라 앞으로. O(n²), 불안정 정렬.
삽입 정렬 — 정렬된 구간에 원소를 삽입. O(n²), 거의 정렬된 데이터에 유리.
합병 정렬 — 분할 정복, 두 구간을 합치며 정렬. O(n log n), 안정 정렬, 추가 메모리 사용.
퀵 정렬 — 피벗 기준 분할 후 재귀. 평균 O(n log n), 최악 O(n²), 보통 가장 빠름.
힙 정렬 — 힙을 이용해 최댓값을 차례로 제거. O(n log n), 추가 메모리 거의 없음.
이진 탐색 — 정렬된 배열에서 절반씩 범위를 줄이며 탐색. O(log n).

해시 맵

체이닝 — 해시 충돌 시 같은 버킷에 연결 리스트로 저장. 구현이 단순하고 충돌 처리 명확.
오픈 어드레싱 — 충돌 시 다른 빈 버킷을 찾아 저장. 선형/이차 탐사, 더블 해싱 등.

그래프

그래프 기초 — 정점(Vertex)과 간선(Edge). 방향/무방향, 가중치, 인접 리스트·행렬 표현.
DFS / BFS — 깊이 우선 탐색(스택/재귀), 너비 우선 탐색(큐). 경로 탐색, 연결 요소 등.
다익스트라 — 음수 간선 없을 때 한 정점에서 모든 정점까지 최단 거리. O((V+E) log V) 등.
플로이드 워셜 — 모든 쌍 최단 경로. 3중 루프로 DP 갱신. O(V³).
벨만 포드 — 음수 간선 허용. 음수 사이클 감지 가능. O(VE).
최소 신장 트리(MST) — 모든 정점을 잇는 트리 중 간선 가중치 합 최소. 크루스칼, 프림 알고리즘.
